حلقتي PWA v2.9

ارفع جميع الملفات الموجودة داخل هذه الحزمة إلى جذر موقع الـPWA:
- index.html
- 404.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

مهم لتسجيل Google:
بعد معرفة رابط الموقع النهائي، أضفه داخل:
Supabase > Authentication > URL Configuration > Redirect URLs

مثال GitHub Pages:
https://YOUR-USERNAME.github.io/YOUR-REPO/**

ملاحظات:
- الـPWA يعرض الواجهة المخزنة فوراً عند فتحه دون إنترنت بعد أول تشغيل ناجح.
- الجلسات والحضور والسلوك والتسميع تعمل بنظام الحفظ المحلي/المزامنة الموجود في v2.9.
- مكتبات الواجهة وبيانات QCF4 يتم تخزينها بواسطة Service Worker أثناء الاستخدام المتصل حتى تتوفر لاحقاً دون اتصال.
- تسجيل الدخول الجديد بحساب Google يحتاج اتصالاً بالإنترنت، لكن الحساب والبيانات المخزنة سابقاً يمكن فتحها دون اتصال.
