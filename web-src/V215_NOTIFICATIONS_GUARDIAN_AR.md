# حلقتي v2.15.0 — الإشعارات وولي الأمر

## ما تمت إضافته
- مركز إشعارات داخل التطبيق مع عداد غير المقروء وزر جرس في الشريط العلوي.
- صلاحية الإرسال اليدوي لمسؤول النظام **ومشرف الحلقة**.
- مسؤول النظام: إرسال لكل الحلقات أو حلقة أو فئة أو طالب.
- مشرف الحلقة: إرسال فقط للحلقات/الفئات/الطلاب الذين يشرف عليهم.
- اختيار الجمهور: أولياء الأمور، المحفظون، أو كل المرتبطين.
- إشعارات تلقائية بعد نجاح المزامنة للحضور/الغياب/التأخر، السلوك، والتقرير اليومي للحفظ/المراجعة/السرد والتعليقات والواجب.
- إنجاز تلقائي عند تسجيل حفظ جزء كامل باستخدام اختيار «الأجزاء».
- الإعلانات التي ينشرها مسؤول النظام أو مشرف الحلقة تُحوّل أيضًا إلى إشعارات للمستهدفين.
- تفضيلات لكل مستخدم: Push، حضور، تسميع، سلوك، إعلانات، إنجازات.
- آخر ثلاثة إشعارات تظهر في لوحة ولي الأمر مع رابط لمركز الإشعارات.
- Deep links: إشعار الطالب يفتح ملف الطالب، وإشعار الإعلان يفتح المجتمع/الإعلانات.
- تسجيل أجهزة Android في `user_devices` وإلغاء الجهاز عند تسجيل الخروج.

## الأمان
- الإرسال يتم عبر Edge Function `halaqati-notify` مع JWT.
- المستلمون يتم حسابهم على الخادم، وليس من قائمة يرسلها الهاتف.
- المشرف لا يستطيع الإرسال لحلقة ليست له.
- مسؤول النظام وحده يستطيع الإرسال لكل الحلقات.
- RLS مفعّل على `notifications`, `notification_preferences`, `user_devices`.
- مفاتيح Firebase لا توضع داخل JavaScript.

## Push الخارجي
البنية البرمجية جاهزة، لكن FCM يحتاج إعداد Firebase مرة واحدة. راجع `FIREBASE_PUSH_V215_SETUP_AR.md`.
بدون Firebase يبقى مركز الإشعارات الداخلي يعمل بالكامل، ويظهر Push كـ skipped بدل تعطيل التطبيق.
