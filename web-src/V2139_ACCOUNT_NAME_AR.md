# حلقتي v2.13.9 — اسم الحساب الكامل

التغيير مخصص لتعريف اسم صاحب الحساب، خصوصاً ولي الأمر.

- بعد تسجيل الدخول بحساب Google لأول مرة يظهر مربع لتأكيد/تعديل الاسم الكامل.
- الاسم الذي يتم حفظه هو `profiles.full_name`، وهو الاسم المستخدم في قوائم الحسابات وأولياء الأمور.
- يمكن تعديل الاسم لاحقاً من: الإعدادات ← اسم الحساب ← تعديل الاسم الكامل.
- الحسابات المعلقة قبل الاعتماد يمكنها أيضاً تعديل الاسم من شاشة انتظار الاعتماد.
- يتم حفظ علامة تأكيد الاسم داخل `profiles.preferences.account_name_confirmed` حتى لا يتكرر السؤال بعد التأكيد.
- لا يوجد تغيير في PDF أو المزامنة أو الجلسات أو الطلاب أو صلاحيات قاعدة البيانات. سياسة `profiles_update` الحالية تسمح للمستخدم بتعديل ملفه الشخصي فقط، أو للمسؤول بالتعديل.
