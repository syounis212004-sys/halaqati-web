# حلقتي v2.40.1 — إصلاح PDF Auto-fit

هذا إصدار تصحيحي فوق v2.40.0 Live Halaqa.

## ما تم إصلاحه
- إصلاح التقرير الذي كان يُظهر عمودي # والطالب فقط ويقص بقية الأعمدة في PDF.
- جميع جداول التقرير أصبحت محصورة داخل عرض صفحة A4 تلقائيًا.
- اسم الطالب يبقى في سطر واحد، مع تصغير آمن لحجم خط خلية الاسم فقط عند الضرورة القصوى.
- الأعمدة الرقمية تأخذ أقل عرض مناسب، بينما الفئة والمسار والنصوص الطويلة تتوزع تلقائيًا داخل المساحة المتبقية.
- إعادة تطبيق Auto-fit على نسخة صفحة الرندر نفسها قبل html2canvas لمنع اختلاف المعاينة عن الملف النهائي.
- html2canvas صار يلتقط حدود الصفحة الملائمة صراحةً بدل قص الأعمدة الخارجة في RTL.

## الجودة محفوظة
- Cairo كما هو.
- 300 DPI كما هو.
- PNG Lossless كما هو.
- لا JPEG.
- لا FAST image compression في مسار PDF الشامل.
- طبقة النص العربي القابلة للبحث والتحديد والنسخ باقية كما هي.

## لا تغييرات قاعدة بيانات
لا يحتاج هذا الإصدار إلى SQL أو Migration جديد.
