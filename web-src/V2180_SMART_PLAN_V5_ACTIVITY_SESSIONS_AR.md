# حلقتي v2.18.0 — Smart Plan V5

## التغييرات
- تقييم V5 بنسبة سلامة: الخطأ = 1، النقرة = 0.25، ممتاز >85%، جيد جداً 75–85%، جيد 70–<75%، أقل من 70 يحتاج إعادة.
- المقاطع الأقل من صفحة تستخدم صفحة واحدة كمقام للتقييم فقط حتى لا يُظلم الطالب الصغير.
- الحد الأدنى الافتراضي للحفظ في يوم الدوام = صفحة واحدة، والتقدم الزائد لا يعفي من واجب اليوم التالي.
- البطاقة تعرض المطلوب والمنجز والمتبقي والتقدم، آخر تسميع، المقرر القادم، وشرح «لماذا هذا المقرر؟».
- «جيد» لا يوقف الحفظ؛ يحتاج إعادة فقط يوقف الانتقال مؤقتاً.
- مسار السرد والتثبيت يدعمان اتجاهين: الناس ← البقرة أو البقرة → الناس، مع تصاعد الآيات داخل السورة دائماً.
- يوم سرد أسبوعي + أسبوع سرد مكثف؛ أسبوع السرد يوقف الحفظ الجديد مؤقتاً ثم يستأنفه بعد نهايته.
- جلسة تربوية/تفاعلية لا تسجل تسميعاً: قصة/توعية/مسابقة/قيمة أسبوع، مع درجة نشاط ومشاركة منفصلة عن نقاط الحفظ.
- واجهة ولي الأمر تعرض نفس الخطة بشكل مبسط: المطلوب، المنجز، آخر تسميع، الأخطاء والنقرات، والمقرر القادم.
