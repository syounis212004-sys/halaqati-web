# حلقتي v2.13.7 — إصلاح سرد الأجزاء + حذف الحلقة الآمن

## ما تم إصلاحه
- قاعدة البيانات أصبحت تقبل `juz` عند تسجيل التسميع/السرد بالأجزاء.
- قاعدة البيانات أصبحت تقبل `import` لمسار استيراد التسميعات القديمة.
- أضيف تطبيع احتياطي لطريقة الإدخال قبل المزامنة لمنع إرسال قيمة غير معروفة.

## حذف الحلقة
- زر «حذف الحلقة» يظهر لمسؤول النظام فقط.
- يتطلب اتصالاً بالإنترنت.
- يعرض عدد الطلاب والجلسات قبل الحذف.
- يتطلب كتابة اسم الحلقة كاملًا ثم تأكيدًا ثانيًا.
- الحذف يتم من خلال RPC محمي لمسؤول النظام فقط، ويحذف الطلاب أولًا ثم الحلقة.
- علاقات قاعدة البيانات المتسلسلة تحذف حضور الطلاب وتسميعاتهم وملاحظاتهم وخططهم ونقاطهم وروابط أولياء الأمور، ثم جلسات الحلقة وفئاتها وإعلاناتها ومنشوراتها وربط المشرفين والمحفظين وسجلات الاستيراد والزيارات.

## ما لم يتغير
- محرك PDF العربي 300 DPI القابل للبحث لم يُعدّل.
- Auth/Students/Sessions/Settings modular architecture بقيت كما هي.
- لم تتغير واجهة الجلسات أو طريقة احتساب مقدار السرد.
