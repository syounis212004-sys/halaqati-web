# حلقتي v2.17.1 — إصلاح مزامنة الخطط وتقريب الهدف

- يمنع إرسال الحقول المؤقتة `lineKeys` و`steps` وغيرها كأعمدة إلى جدول `smart_plans`.
- يحفظ في Supabase فقط الأعمدة المعتمدة في مخطط `smart_plans`؛ وهذا يحل خطأ schema cache الخاص بـ `lineKeys`.
- حقل عدد صفحات الحفظ يقبل رقماً طبيعياً أو عشرياً، ثم يقرّبه تلقائياً للأعلى قبل إنشاء الخطة: 20.5 ← 21.
- أزيل تعارض HTML الذي كان يجعل القيمة الصحيحة ضمن تسلسل مثل 20.97 و21.07 بسبب `min=0.07` مع `step=0.1`.
- ما زال حساب نهاية الخطة يكمّل الآية كاملة، ويعرض المقدار الفعلي الدقيق الناتج من سطور المصحف.
- لا يوجد تغيير جديد مطلوب في قاعدة البيانات إذا تم تشغيل Migration v2.17 سابقاً.
