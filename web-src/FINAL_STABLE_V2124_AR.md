# حلقتي v2.12.4 - إصلاح PDF النهائي

## سبب ملف PDF الأبيض في v2.12.3

كان تقسيم الجدول ينشئ صفحات مؤقتة داخل عنصر مخصص للقياس يحتوي على `visibility:hidden`، ثم كان `html2canvas` يصوّر تلك الصفحات وهي ما زالت داخل العنصر المخفي. النتيجة: ملف PDF صحيح من حيث عدد الصفحات، لكن كل الصفحات بيضاء.

## الإصلاح في v2.12.4

- عنصر القياس المخفي يُستخدم للقياس فقط.
- قبل التصوير تُنقل كل صفحة إلى Render Stage مرئي داخل معاينة التقرير.
- يتم الانتظار حتى تكتمل الخطوط ودورتا رسم للمتصفح قبل `html2canvas`.
- يوجد فحص آلي للصورة الناتجة؛ إذا كانت بيضاء تتم محاولة ثانية بدقة أخف.
- إذا بقيت بيضاء لا يتم حفظ PDF فارغ إطلاقاً، بل تظهر رسالة خطأ.
- الجداول ذات الصفوف الطويلة تُقسّم على حدود `<tr>`، ولا يعاد قص الصفحة بعد التقسيم.
- إذا زاد ارتفاع صفحة آمنة قليلاً بسبب اختلاف القياس في WebView، يتم تصغير الصفحة كاملة بدلاً من قطع صف طالب.
- الصفحات غير الجدولية الطويلة تستخدم نقاط قطع آمنة مشتقة من حدود صفوف الجداول والعناوين والفوتر لتقليل قطع المحتوى.
- بقيت معاينة PDF، تغيير الخط، حجم الخط، اللون، Zoom، والوضع الأفقي/الرأسي كما هي.
- لم تتغير الإعدادات أو تسجيل الدخول أو الطلاب أو الحلقات أو Supabase أو منطق الاستيراد.

## الفحوصات المضافة

- JavaScript syntax checks.
- Regression check للإعدادات والمعاينة وتصدير الطلاب ومكان Excel التقارير.
- Regression check لمسار PDF المرئي وBlank guard وعدم إعادة تقطيع الصفوف.
- Browser PDF smoke test في GitHub Actions باستخدام Chrome/Chromium و`html2canvas` الحقيقي بعد بناء Vite؛ يفشل الـBuild إذا خرج Canvas أبيض أو ضاع/تكرر صف من 22 صفاً في اختبار التقسيم.
