# حلقتي v2.12.2 — إصلاح مستقر ومحدود

هذه النسخة مبنية من v2.12 Phase 1 المستقرة، ثم أُعيد تطبيق تعديلات التصدير وPDF بشكل جراحي فقط.

## تم إصلاحه
- استعادة صفحة الإعدادات وكل دوال المظهر وكلمة المرور.
- زر PDF في صفحة التقارير يفتح المعاينة الداخلية مباشرة، دون المرور بدالة التصدير القديمة.
- حجم الخط في المعاينة يغير عناصر التقرير فعلياً.
- أفقي/رأسي يغير مقاس المعاينة والملف النهائي فعلياً مع منع تمدد أسماء الطلاب.
- إنشاء PDF من المعاينة بدقة طباعة تقارب 300 DPI وبصيغة PNG داخل PDF.
- صفحة الاستيراد والتصدير تعرض فقط: طلاب Excel، طلاب Word، طلاب PDF.
- تقرير Excel بقي في صفحة التقارير فقط.
- Excel على Android يستخدم نظام الحفظ/المشاركة الخاص بالتطبيق.
- Word وPDF للطلاب يستخدمان نفس مجموعة البيانات الأساسية.

## لم يتم تغييره
Auth، Google Login، Supabase، RLS، الجلسات، الطلاب، الحضور، التسميع، الحاسبة، الخطط، الصلاحيات، Offline، بنية Vite/Capacitor.

## فحوصات آلية
أضيف `npm run check:regression` للتأكد قبل كل Build من وجود دوال الإعدادات، وربط زر PDF بالمعاينة، وعدم عودة تقرير Excel إلى صفحة التصدير.
