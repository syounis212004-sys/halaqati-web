# حلقتي v2.12.5 — PDF قابل للبحث بدون تغيير الشكل

هذه النسخة مبنية مباشرة فوق v2.12.4 المستقرة.

## ما الذي تغير فقط؟

- بقيت الصفحة المرئية داخل PDF كما هي: صورة PNG عالية الجودة بحوالي 300 DPI ناتجة من html2canvas.
- أضيفت فوق الصورة طبقة Unicode غير مرئية داخل PDF تحتوي النص الحقيقي للتقرير.
- الطبقة غير المرئية تسمح بالبحث Search، وتحديد النص، ونسخه، بما في ذلك أسماء الطلاب العربية.
- النص المضاف للبحث يؤخذ من DOM الخاص بالمعاينة بعد التعديلات، لذلك إذا عدّل المستخدم النص قبل الحفظ فالنص المعدل نفسه يدخل إلى طبقة البحث.
- لم يتم تغيير أي عنصر مرئي في تصميم PDF.

## الأشياء التي بقيت كما كانت في v2.12.4

- تعديل النص يدوياً داخل المعاينة.
- نوع الخط المرئي: Cairo / Tahoma / Arial / Serif.
- حجم الخط 8–18.
- لون النص.
- لون العناوين.
- Zoom.
- A4 أفقي / رأسي.
- دقة PNG العالية.
- منع تقسيم صف الطالب بين صفحتين.
- تكرار رأس الجدول في صفحات المتابعة.
- منع حفظ PDF أبيض.

## طبقة البحث

يتم تضمين خط Arabic Unicode TTF مستقل داخل PDF من أجل طبقة النص غير المرئية فقط. هذا الخط لا يظهر للمستخدم ولا يغير الشكل؛ الشكل النهائي يبقى من صورة المعاينة نفسها.

## اختبارات البناء

قبل إنشاء APK يقوم GitHub Actions بـ:

1. فحص JavaScript وRegression لكل عناصر المعاينة والإعدادات.
2. فحص Browser حقيقي للتأكد أن html2canvas لا ينتج صفحات بيضاء وأن الصفوف لا تضيع.
3. فحص Browser ثانٍ ينشئ PDF تجريبياً يحتوي أسماء عربية في طبقة نص غير مرئية.
4. يقرأ الـPDF الناتج بواسطة PDF.js ويتأكد أن كلمات عربية مثل «إبراهيم» و«إسماعيل» قابلة للاستخراج.
5. لا يكمل بناء APK إذا فشل أي اختبار.
