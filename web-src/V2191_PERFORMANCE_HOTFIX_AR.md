# حلقتي v2.19.1 — Performance & UX Hotfix

هذا الإصدار تصحيحي فوق v2.19.0 ولا يغيّر نظام الصفحات أو مساري الحلقة.

## أهم الإصلاحات

- إصلاح زري **ابدأ جلسة اليوم** و**التحفيظ السريع** مع استجابة فورية وحماية من فشل الفتح.
- إصلاح اختفاء نص تبويبي **الحفظ العام / التثبيت** بسبب متغير CSS غير موجود.
- لوحة اليوم تحسب **لم يسمّع اليوم** فقط لمن لديه مقرر في يوم دوام فعلي حسب `schedule_weekdays` والخطة الفعالة. في يوم غير مقرر يظهر: **لا يوجد تسميع مقرر اليوم**.
- عرض المقرر بصيغة واضحة: **حفظ: سورة الحديد من آية 25 إلى آية 28** بدل **الحديد 25**.
- نفس الصيغة الواضحة في تقرير ولي الأمر.
- التحفيظ السريع: بطاقة عالية التباين، زر **✓ تمّ التسميع وحفظ**، وخيارات مباشرة **حاضر / غائب بعذر / غائب بدون عذر**.
- تسريع تقارير ولي الأمر: preload لمكتبات التصدير، عدم إعادة بناء البطاقة عند كل تصدير، scale أخف، JPEG مضغوط للصورة وداخل PDF.
- تسريع الواجهة: memoization لحسابات الخطة، فهرسة محلية للتسميع/الحضور/الملاحظات، تقليل أعمدة استعلامات Supabase، `content-visibility` للقوائم الطويلة، وتعطيل blur الثقيل في شريط الهاتف.
- استجابة فورية عند التنقل: Skeleton أولًا ثم الصفحة، مع حركة قصيرة تعتمد opacity/transform فقط.
- Migration أداء منفصل يضيف فهارس آمنة للاستعلامات الأكثر استخدامًا.

## ملاحظة قاعدة البيانات

شغّل `Halaqati-v2.19.1-performance-hotfix-migration.sql` مرة واحدة. الملف لا يغيّر RLS ولا البيانات ولا المسارات؛ يضيف فهارس أداء فقط.
