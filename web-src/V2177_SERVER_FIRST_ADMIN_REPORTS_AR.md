# حلقتي v2.17.7 — الصلاحيات والتقارير Server-First

## الإصلاحات
- صفحة الحسابات والصلاحيات تحاول Supabase مباشرة عند فتحها، مع إعادة محاولة تلقائية إذا كان الخطأ شبكياً.
- آخر قائمة حسابات ناجحة تُحفظ محلياً لمسؤول النظام للعرض فقط عند ضعف الاتصال؛ التعديل/الحذف/تغيير الصلاحيات يبقى Online فقط.
- استوديو التقارير لم يعد يقرر Offline بناءً على فحص صحة قصير قبل الاستعلام؛ يحاول قراءة Supabase نفسها أولاً.
- عند فشل تقرير شبكياً تتم إعادة المحاولة مرة واحدة.
- لا يتم اعتماد كاش محلي ناقص كتقرير جديد. fallback مسموح فقط لآخر تقرير كامل سبق تحميله من الخادم ولنفس مفتاح الفترة/الحلقة/نوع اللقاء.
- إذا لم توجد نسخة كاملة محفوظة، يبقى التقرير غير مجهز وتظهر رسالة واضحة بدل 0 طالب / 0 لقاء بشكل مضلل.
- فحص الاتصال العام أصبح أكثر تحملاً: 3 ثوانٍ ثم محاولة ثانية 1.8 ثانية.

## لا تغييرات على البيانات
لا تحتاج النسخة v2.17.7 إلى Migration جديدة في Supabase.
