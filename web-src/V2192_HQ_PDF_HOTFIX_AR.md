# حلقتي v2.19.2 — HQ PDF Hotfix

هذا إصدار تصحيحي صغير فوق v2.19.1.

## التغيير

- إعادة **PDF تقارير أولياء الأمور** إلى الجودة العالية كما كانت قبل ضغط v2.19.1.
- PDF يستخدم لقطة `html2canvas` بدقة `scale: 2` ثم **PNG lossless** داخل jsPDF.
- تم إلغاء JPEG وضغط `FAST` من مسار PDF بالكامل.
- خيار **الصورة / المشاركة** يبقى سريعًا كما هو في v2.19.1؛ التغيير يخص PDF فقط.
- لا يوجد Migration جديد لقاعدة البيانات.
- جميع تحسينات الأداء، التحفيظ السريع، لوحة اليوم، والمسارين في v2.19.1 تبقى بدون تغيير.
