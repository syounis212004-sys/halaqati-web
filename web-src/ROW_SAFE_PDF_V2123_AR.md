# حلقتي v2.12.3 - إصلاح تقطيع صفوف PDF فقط

هذه النسخة مبنية مباشرة على v2.12.2 المستقرة، ولم تغيّر بنية النظام أو الصفحات أو قاعدة البيانات.

## المشكلة التي تم إصلاحها
كان PDF يُنشأ عبر صورة طويلة للتقرير ثم تُقص الصورة كل ارتفاع صفحة A4. إذا وقع حد الصفحة داخل صف طالب، ينقسم الصف بين صفحتين (مثل الطالب رقم 18 في التقرير المرفق).

## الحل
- اكتشاف التقرير الطويل الذي يحتوي جدولاً واحداً.
- إنشاء صفحات PDF داخلية منفصلة قبل التصوير.
- نقل صفوف `<tr>` كاملة إلى الصفحة التالية بدلاً من قصها نصفين.
- تكرار رأس الجدول في كل صفحة تلقائياً.
- في صفحات المتابعة يتكرر رأس التقرير ومعلومات الحلقة والفترة مع عبارة "تابع التقرير" ورقم الصفحة.
- الإبقاء على جودة 300 DPI الحالية، ومعاينة PDF، والتحكم بالخط واللون والاتجاه كما هي.
- عدم تعديل الإعدادات أو Auth أو الطلاب أو التقارير أو الاستيراد/التصدير أو قاعدة البيانات.

## فحص regression
أضيف فحص يتأكد أن دالة `buildRowSafePdfPages` موجودة وأن النسخة هي 2.12.3 قبل السماح للـBuild بالاستمرار.
