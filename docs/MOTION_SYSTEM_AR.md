# نظام الحركة المركزي لموقع حلقاتي (Motion System)

## جرد الحركة قبل التعديل
- 40+ `@keyframes` موزّعة على 20 ملف CSS (nrSlide، uxSheetIn، rc27in، dnRise، nhBreathe…) بمدد ومنحنيات مختلفة.
- انتقال الصفحات: View Transitions في `features/rc54/motion.js` (انزلاق 26px + تلاشٍ) بلا تتابع للعناصر.
- مشاهد Lottie للحالات (`features/rc27/motion.js`): splash وloading وempty وsuccess.
- الحوارات: `uxSheetIn` للجوال فقط، بلا خروج وبلا backdrop متحرك. القائمة الجانبية: `transition:.25s` بلا تباين دخول/خروج.
- شريط التنقل: يُعاد بناؤه بالكامل عند كل تنقل، فلا انتقال للمؤشر النشط.
- وضع «الحركة: مخففة» وتفضيل النظام كانا يُلغيان كل شيء (`animation:none!important`) دون تدرّج.

## النظام الجديد
| الطبقة | الملف | المسؤولية |
|---|---|---|
| رموز التصميم | `src/styles/motion.css` (`--hm-dur-*`, `--hm-ease-*`, `--hm-dist-*`, `--hm-stagger`, `--hm-start`) | مصدر واحد للمدد والمنحنيات والمسافات (تقرأه JS أيضًا) |
| CSS | `motion.css` | الحوارات (دخول/خروج/backdrop بلا JS)، القائمة الجانبية، الضغط، التوست، تخفيف الحركة المتدرّج |
| JS | `src/core/motion-system.js` | تتابع دخول الصفحة (Web Animations)، عدّاد الأرقام (GSAP)، مؤشر التنقل المنزلق، علامة النجاح المرسومة (DrawSVG)، رسم الزخرفة الهندسية في شاشة الدخول |

المكتبة الوحيدة المضافة: `gsap@3.13.0` (النواة + DrawSVG، مجانيان). لا ScrollTrigger ولا تمرير مخصّص.

## القواعد
- transform وopacity فقط؛ الدخول أبطأ من الخروج؛ اتجاه RTL عبر `--hm-start`.
- كل حركة مُتتبَّعة؛ أي render جديد أو تبويب مخفي أو تغيّر تفضيل الحركة ينهيها عند حالتها النهائية (لا بقايا style).
- تخفيف الحركة: الطبقة 1 (الانزلاق/التحجيم) تُزال، الطبقة 2 تصبح تلاشيًا ≤150ms، الطبقة 3 (الألوان والتركيز والدوّارات) تبقى.
- مفتاح إيقاف: `HalaqatiMotion.off = true` أو `localStorage.halaqati_motion_off=1` يعطّل التتابع فقط.

## الاختبار
`BASE_URL=http://127.0.0.1:5173/ node scripts/motion-check.mjs` (متصفح حقيقي، يقيس عبر الزمن لا لقطات ثابتة).

## الإصدار الثاني: الاستمرارية (Continuity)
مراجعة بصرية عبر الزمن (تسجيل CDP + شبكات لقطات) كشفت أن الإصدار الأول كان «طبقة فوق» الواجهة لا نظام انتقال متصل. ما تغيّر:

| الحركة | قبل | بعد |
|---|---|---|
| تغيير الصفحة | `go()` كان يستبدل الصفحة القديمة فورًا بهيكل تحميل أبيض (وميض ~150ms) فتلتقط الـView Transition الهيكل لا الصفحة | الصفحة القديمة تبقى حتى جاهزية الجديدة وتتلاشى متداخلةً مع دخول الجديدة؛ الهيكل لا يظهر إلا بعد 260ms (صفحة بطيئة فعلًا) |
| تتابع الدخول | حتى 0.42s من التأخير الإضافي | تأخير إجمالي ≤0.23s؛ المحتوى مقروء أسرع |
| توسّع/طيّ البطاقة (الطلاب) | الأيقونة تتبدّل صورتين؛ المحتوى يختفي فورًا عند الطيّ | أيقونة واحدة تدور 180°؛ المحتوى يبقى مرئيًا أثناء الانطواء ثم يُخفى |
| توسّع بطاقة الحضور (إعادة رسم في مكانها) | قفز | FLIP بالموضع فقط: ما تحتها ينزلق، البطاقة تُكشف بقصّ، السهم يدور؛ الطيّ أسرع من التوسّع |
| إعادة رسم نفس الصفحة (فرز/تصفية/تحديث بيانات) | بلا استمرارية | العناصر المستمرة تنزلق من موضعها السابق، الجديدة تتلاشى، لا تُعاد حركة الدخول |
| هيكل التحميل ← المحتوى | قطع فجائي | تلاشٍ بالشفافية فقط + عدّاد من الصفر |
| القائمة الجانبية | CSS فقط (ينقر ويغلق) | + سحب بالإصبع يتبع الموضع، يُحسم بالمسافة أو سرعة الدفع، ويكمل من موضع الإصبع دون قفز؛ سحب عمودي يبقى تمريرًا أصيلًا |
| حالة الفراغ | أيقونة ثابتة | نجمة هندسية ثمانية تُرسم مرة واحدة خلف الأيقونة (لا فوق بيانات ولا نماذج) |

### الواجهة البرمجية الجديدة
`HalaqatiMotion.flip(() => { /* حدّث الـDOM */ })` للميزات التي تحدّث جزءًا من الصفحة دون `render()`؛ يلتقط مواضع العناصر المفتاحية (`[data-stcard]`, `[id^="roster_"]`, `[data-id]`, `[data-sid]`, `[data-key]`) ثم يشغّل FLIP في نفس المهمة (لا يُرسم التخطيط النهائي قبل الحركة). يُتجاهل تلقائيًا مع تخفيف الحركة أو إيقاف النظام.

### أدوات الفحص
- `scripts/motion-record.mjs`: تسجيل الحركة عبر الزمن (CDP screencast) وتجميع شبكة لقطات `sheet.png` (+`movie.mp4`) لكل مشهد.
- `scripts/motion-check.mjs`: فحوص سلوكية؛ يشمل الآن الاستمرارية، FLIP، هيكل ← محتوى، سحب القائمة، الأيقونة الواحدة، الزخرفة، والأدوار الخمسة.

## تدقيق الحركة (منهج web-motion-auditor)
- الإصدار: web 2.91.3 + commits الاستمرارية (انظر سجل git بعد `0fcb076`)؛ ‎Chromium 1.x المثبّت (Playwright)، بيانات تجريبية بلا شبكة.
- العرض: 390×844 (هاتف) و1440×900 (حاسوب)؛ نمط الإدخال: مؤشر/لمس **مُحاكى** عبر CDP (لا جهاز فعلي)؛ تفضيل الحركة: no-preference وreduce (emulate) والمفتاح الداخلي.
