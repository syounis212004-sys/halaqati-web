# الويب 2.88.0-web.1 — مطابقة التطبيق RC52

- مكافأة الطالب كاملة (مبلغ/هدية، خيارات المدير، موافقة، تحويل وإثبات، استلام، تسليم، شكر) مع شريط تتبّع.
- محادثة لكل طلب مكافأة وكل كفالة بين المانح والمدير فقط.
- سياسة منع تكرار المكافأة وخيارات المكافأة من المدير (تبويب «المكافآت»).
- نوع حساب «مانح» عند التسجيل وإكمال الحساب والاعتماد.
- منتقي أشهر حقيقي، وتبويبات بمؤشر منزلق وانتقال سلس.
- ولي الأمر: «نظرة اليوم»، شارات أصعب (شهرية وموسمية)، إنجازات بمنتقي فترة.
- الموظفون: سجل التسميعات (طالب × أيام، Excel/Word) والملخص الأسبوعي، وإنهاء الجلسة الذكي.
- شعار المركز/الحلقة الافتراضي يظهر للمدير فقط. إزالة «الشرقية — خانيونس».
