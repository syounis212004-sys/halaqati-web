# حلقاتي RC27.39 — تحديث الويب

نسخة الويب: `2.63.39-web.1`. مصدرها تطبيق أندرويد RC27.39 المرفق، مع الاحتفاظ بمصدر الويب الحالي ووظائفه الموجودة.

## ما تغير

- الجلسة الجديدة تستخدم إنشاء/فتح جلسة اليوم على الخادم، وتُربط عمليات الحضور والتسميع بمعرفها المعتمد. إغلاق جلسة قبل رفعها يحتفظ بطلب الإنشاء وحالتها الأخيرة، والتعديل أثناء المزامنة يبقى في الطابور.
- تعديل تاريخ الجلسة والحلقة والنوع يستخدم دالة أندرويد نفسها التي تحدث الخطط والأرشيف والشارات. الأرشفة والاستعادة تحفظ بقية بيانات الجلسة.
- الشهادات تستخدم أرشيف RC24 المشترك بين الأجهزة: ترقيم رسمي حسب السلسلة، نسخ مصححة، سجل نسخ، وإلغاء بسبب محفوظ. صور الشعارات والتواقيع تبقى محلية.
- إعادة المحاولة بعد انقطاع رد الإصدار تستعيد النص الرسمي المحفوظ، والإصدار الجماعي يستخدم سطح تصدير مستقل ويحافظ على أرقام المحاولات السابقة عند تعثر تنزيل PDF.
- قبل الطباعة أو التصدير الرسمي يُقرأ وضع الشهادة الحالي من الخادم لمنع تصدير شهادة ملغاة أو نسخة أصبحت قديمة. المشاهدة المحلية تبقى متاحة دون اتصال.
- الأرشيف المحلي السابق محفوظ ويمكن تصديره أو استيراد سجلاته القديمة إلى المشترك بإجراء صريح؛ لا تُمسح السجلات القديمة تلقائيًا.
- المقارنات وبيانات البرامج والمراحل وترتيب شهادات المراكز تُقرأ على صفحات كاملة، بما فيها الطلاب بعد أول 300 طالب. فشل القراءة لا يتحول إلى ترتيب ناجح ناقص.
- تنبيهات صحة الخطة تستخدم حالة RC19 ومفتاح الحلقة المتتابعة نفسه المستخدم في أندرويد؛ لا يُسجّل وصول التنبيه إذا فشل إرساله.
- كاش لوحة المتابعة مربوط بالحساب والحلقة، والعمليات المتأخرة لا تعيد بيانات الحساب السابق. تُحفظ لقطات المراحل المناسبة للحساب عند العمل دون اتصال.
- واجهة واحدة متجاوبة: قائمة ثابتة للكمبيوتر، تنقل سفلي للجوال، حوارات قابلة للتمرير، تفضيل عرض دون إعادة تحميل، دون إطار iframe، وواجهة داكنة.
- الموقع قابل للتثبيت كـPWA حين يدعم المتصفح ذلك، مع إرشادات عند عدم توفر نافذة التثبيت. تحديث الموقع لا يعيد تحميل عمل غير محفوظ أو عمليات معلقة.
- GitHub Pages يبني مصدر `web-src` الذي اجتاز الاختبارات، بدل اختيار ZIP قديم. ملفات تحديث أندرويد `Halaqati-latest.apk` و`version.json` لم تتغير في هذا التحديث.

## الروابط بعد نشر الفرع

- تلقائي: `https://syounis212004-sys.github.io/halaqati-web/`
- الجوال: `https://syounis212004-sys.github.io/halaqati-web/?view=mobile`
- الكمبيوتر: `https://syounis212004-sys.github.io/halaqati-web/?view=desktop`

هذه ليست ملفات EXE أو APK جديدة. كلا العرضين من الموقع نفسه وبنفس حسابات Supabase.

## التحقق

```sh
cd web-src
npm ci
npm run check:parity
npm run check:offline-sync
npm run check:data-integrity
npm run build
npm run preview -- --host 127.0.0.1
# في نافذة ثانية، مع Chromium مثبت أو npx playwright install chromium:
npm run check:browser
```

اختبارات المتصفح تستخدم بيانات معزولة وتمنع الاتصالات الخارجية. تغطي إنشاء PDF جماعيًا، منع إصدار مكرر بعد تعثر التنزيل، الاستعادة بعد فقد رد الخادم، منع تصدير شهادة ملغاة، وحماية التعديلات من تحديث الصفحة. فحص العرض يشمل 360 و390 و768 و1024 و1440 بكسل، مع معاينة أدوار المدير والمشرف والمحفظ وولي الأمر والوضع الداكن.

تمت قراءة تعريفات قاعدة البيانات الفعلية في المشروع المطابق لإعدادات الموقع: دوال RC18.2 وRC19 وRC23 وRC24 وRC25 المطلوبة موجودة بتوقيعاتها المتوقعة، والجداول المعنية مفعّل عليها RLS. لم تُعدّل بيانات الإنتاج ولم تُشغّل migrations. هذا يثبت توفر العقود، ولا يغني عن اختبار دخول وتفاعل بحسابات الأدوار الفعلية.

## تصدير الشهادات العربية

تنزيل شهادة من المتصفح يحفظ صورة عالية الدقة (240 DPI) داخل PDF لضمان مطابقة ترتيب العربية للمعاينة. النص داخل هذا التنزيل غير قابل للبحث أو التحديد. خيار الطباعة من المتصفح يحافظ على النص، وأندرويد يبقى على محرك Chromium المتجهي. جرى توليد ملف حقيقي من محرك الويب وفحصه بصريًا، وليس الاكتفاء بمحاكاة زر التنزيل.

## الحدود المعروفة

- الإشعارات داخل الموقع متاحة؛ Web Push أثناء إغلاق المتصفح يحتاج إعداد إرسال خاصًا بالويب. لا يُعرض كميزة مفعّلة بمجرد تثبيت PWA.
- الخطوط المخصصة المثبتة على جهاز معين لا تُنقل إلى جهاز آخر ضمن أرشيف الشهادات.
- استيراد سجل قديم لا يعوّض ملفات صوره الأصلية أو يضمن مطابقة مظهره القديم؛ الأصل المحلي يبقى محفوظًا للمراجعة.
- تغيير بيانات جلسة موجودة، إصدار شهادة رسمية، تصحيحها، والتحقق قبل تصديرها تحتاج اتصالًا بالخادم. إدخال الحضور والتسميع والعمل المحلي يبقى ضمن مسار offline الحالي.

## حالة الرفع

التنفيذ محفوظ على الفرع المحلي `codex/rc27-web-parity`. حاول الربط إنشاء شجرة التغييرات ثم فرع جديد؛ رفض GitHub العمليتين بـ403 `Resource not accessible by integration`، وقائمة تثبيتات الربط فارغة. لم يتغير الموقع المنشور ولم يُنشأ طلب دمج. الحزم المرفقة تتيح نقل المصدر وبناء الموقع أو نشر ملفات الموقع المبنية مباشرة. صلاحيات الحساب التي تظهر في معلومات المستودع لا تكفي لإثبات صلاحية التطبيق المرتبط للكتابة.
