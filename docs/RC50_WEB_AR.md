# الويب 2.86.0-web.1 — مطابقة التطبيق (RC28 → RC50)

**ما نُقل في هذا الإصدار** (كله يستدعي دوال الخادم نفسها التي يستدعيها التطبيق، بلا أي تعديل على قاعدة البيانات):

- **المانح (RC32/RC40/RC42/RC46–RC50):** رئيسية بملخص لكل شيء، المكرَّمون (منصّة الفائزين وتفاصيل الدرجة وطلب مكافأة)، الدعم (كفالاتي وفرص الدعم وبيانات التحويل مع نسخ وإرسال إثبات التحويل)، أثري (الأثر، الشارات، تقرير الشهر مع مشاركة، سجل العطاء، الأخبار، صندوق الاقتراحات)، الإحصاءات (7/30/90 يومًا، الحلقات، الطلاب، تفاصيل الطالب، الطلبات). شريط سفلي: الرئيسية · المكرَّمون · الدعم · أثري · المزيد.
- **المدير:** «التكريم الشهري» (حساب/اعتماد/استبعاد/إذن رقم ولي الأمر) و«الدعم والمانحون» (بطاقات الدعم بمبلغ وعملة ₪/$/د.أ، حساب افتراضي، تأكيد الاستلام وإثبات التسليم، حلقات المانح، الأخبار والاقتراحات).
- **الشكل (RC41/RC47):** بطاقات بيضاء كبيرة الزوايا بظل ناعم، بطل زمردي بنجمة ثمانية، عناوين بخط أميري، تبويبات مقسّمة وأقراص خفيفة، وضع داكن متسق.
- **التنقل (RC40/RC42):** شريط سفلي للموظفين (الرئيسية · الجلسات · ＋ · الإعلانات · المزيد)، قائمة «إضافة سريعة»، شبكة اختصارات في رئيسية المدير/المشرف/المحفّظ.

**لم يُنقل بعد:** سجل التسميعات الجدولي وتصديره (RC42/43)، الملخص الأسبوعي وتقرير أولياء الأمور الجديد (RC43)، إنهاء الجلسة الذكي وإنهاء السرد الجماعي، صور الطلاب والشعار لكل حساب، ومحرّك النطاق الواحد للحفظ والسرد (RC34–37 وRC44–45). هذه تلمس محرّك الخطط والتقارير وتحتاج مطابقة أرقام دقيقة مع التطبيق.
